常见问题 / FAQ

提示"Runtime 未嵌入"或解释器一直未就绪 / "Runtime not embedded"

嵌入式 Python 运行时随 App 一起分发。若状态一直未就绪，请彻底退出 App 后重新打开；仍无效时从 App Store 重装最新版。重装不会删除你已保存的项目文件。

Quit and reopen the app; if the runtime still isn't ready, reinstall from the App Store. Your projects are kept.

安装包失败 / Package installation fails

包安装需要网络，依赖会装到当前项目的 packages/ 目录。纯 Python 包通常可直接安装；含二进制扩展的原生库需要为 iOS 预编译的版本，若没有对应版本会失败，这属于平台限制而非 App 故障。

Installing packages requires network access. Pure-Python wheels install normally; binary extensions need iOS-built wheels, otherwise installation fails by design.

运行中的脚本点 Stop 没反应 / Stop button doesn't interrupt a script

停止通过 KeyboardInterrupt 生效，无法打断阻塞在 C 层调用中的脚本（例如 time.sleep 或某些原生库的长任务）。调试器的断点暂停与求值走独立通道，不受此限制。

Interruption can't break calls blocked inside native code (e.g. time.sleep). Debugger pause/eval uses a separate channel and still works.

Git push/pull 认证失败 / Git authentication fails

请检查 设置 → Git 与凭据 中该主机是否已保存用户名与令牌（令牌存于钥匙串，留空表示沿用原值）。HTTPS 远端需使用访问令牌而非账号密码；SSH 远端需先在 设置 → SSH Hosts 中保存主机与凭据。

HTTPS remotes require a personal access token; SSH remotes require a saved host with credentials under Settings → SSH Hosts.

SSH 提示主机密钥已变更并被拒绝 / "host key changed" error

主机密钥采用"首次信任"机制并保存 SHA256 指纹。指纹变化通常是服务器重装或密钥轮换，也可能是中间人风险。请先在服务器侧核对指纹，确认无误后再在 App 内删除该主机并重新连接。也可通过 设置 → SSH Hosts → Import known_hosts 预先导入指纹。

Verify the new fingerprint on the server itself before trusting it again; you can import known_hosts to pin keys in advance.

AI 助手没有回复 / The AI assistant doesn't respond

AI 功能需要网络，并依赖你自己配置的服务商。请确认 设置 → AI 模型服务 中已填入 API Key（仅存本机钥匙串）、已添加可用模型、接口地址可访问，并检查项目是否拒绝了相关权限请求（读取 / 写入 / 执行 / 联网 / 安装 / Git 分别授权）。

AI calls go to the provider you configure. Check the API key, model list, endpoint reachability, and the per-capability permission prompts.

桌面小组件不显示内容 / Widget shows nothing

小组件只显示摘要（收藏与最近项目、最近一次运行状态），不会在后台运行 Python，刷新时机由系统 WidgetKit 调度。若长期为空，请打开 App 一次让摘要更新。

The widget only mirrors a local summary; refresh is scheduled by WidgetKit. Open the app once to update it.

外接键盘快捷键 / Hardware keyboard shortcuts

支持 ⌘S 保存、⌘F 查找、⌘R 运行、⌘W 关闭标签、⌘P 命令面板等。iPad 上可新建多个窗口，各窗口有独立的项目、标签、输出与会话。

Shortcuts include ⌘S, ⌘F, ⌘R, ⌘W, ⌘P. iPad supports multiple windows with independent sessions.

内购、订阅与退款 / Purchases, subscriptions and refunds

会员（年度会员 / 终身会员）的付款、账单与退款均由 Apple 处理，我们无法看到你的支付方式或 Apple ID，也不在服务器上保存你的交易记录。

换设备或重装后取回权益：请确认使用同一 Apple 账户，然后进入 设置 → PythonDeck Pro → 恢复购买。

取消或管理自动续费：iOS 设置 → 你的姓名 → 订阅；申请退款：Apple 的 reportaproblem.apple.com。

Payments, billing and refunds are handled by Apple — we cannot see your payment method or issue refunds. Use Settings → PythonDeck Pro → Restore Purchases to recover benefits on the same Apple account, and manage renewals in iOS Settings → Subscriptions.

如何备份或迁移项目 / Backup and migration

应用数据保存在本机沙盒中。请通过项目菜单导出 ZIP，或使用 iOS「文件」App 访问应用目录进行备份；换设备时重新导入即可。

Export a project as ZIP, or use the Files app to copy it out, then import it on another device.
