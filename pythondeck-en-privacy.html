PythonDeck Privacy Policy

Platform: iPhone and iPad (iOS/iPadOS) · Bundle ID: com.pythondeck.app
Last Updated: October 8, 2026

1. Overview

PythonDeck is a local Python development environment for iPhone and iPad: an embedded CPython runtime, editor, terminal, Notebook, package manager, Git client, debugger and an optional AI coding assistant. We follow the principle of “data minimization”. The app has no user account, no registration step and no backend of our own. Your projects, code, notebooks, settings and run history stay inside the app’s sandboxed storage on your device by default, and editing and running code work fully offline.

1.1 Purchase and Subscription Verification (StoreKit)

PythonDeck sells two products that unlock the same PythonDeck Pro tier: an Annual Membership (auto-renewable subscription) and a Lifetime Membership (non-consumable purchase). Pro unlocks remote development: an SSH terminal against a server you added, opening and writing back remote files over SFTP, and Git clone/push/pull over SSH. Those features talk to servers you own and configure yourself (see 1.5); we do not relay or retain their content. Verification runs entirely on your device through Apple's StoreKit, and consists of:

  • Your current entitlement state — which membership is active, and the renewal date of the subscription
  • Transaction information that StoreKit hands to the app locally, used only to decide whether Pro features are unlocked

We do not operate a server that receives this information, and we do not write transaction identifiers, receipts or purchase history into your project files, exports or any analytics upload — the app embeds no analytics SDK. Payments, billing details and refunds are handled by Apple; we never see your payment method or Apple ID. Restoring purchases uses StoreKit's own sync, which asks Apple for the transactions tied to the signed-in App Store account. Subscription cancellation and management happen in Apple's subscription settings.

1.2 Data Stored Locally on Your Device

  • Projects, source files, Notebook files and imported assets
  • Editor and app preferences, run history and code snapshots you create
  • Python packages you install into a project

A small summary (project names you mark as favorites or open recently, plus the status of your last run) is shared with the iOS home-screen widget through an Apple App Group container so the widget can show and open your projects. The widget never runs Python code in the background.

1.3 Secrets and Credentials

If you choose to store sensitive values, they are written to the iOS Keychain on your device and are never included in exported files, logs or analytics. This covers:

  • AI service API keys (OpenAI-, Anthropic- or compatible providers you configure)
  • Git account tokens or passwords for HTTPS remotes
  • SSH host passwords and private keys
  • Secret environment variables you define for Mini Apps

These values are not synced to us or to any server we operate. You can view and delete them at any time under Settings → Secrets (Keychain).

1.4 Device Permissions You Grant

The app can expose system capabilities to the Python scripts you run (ios.camera, ios.photos, ios.location, ios.bluetooth, clipboard, share sheet, haptics, notifications). Each capability triggers the standard iOS permission prompt, is used only when you or your script explicitly requests it, and can be revoked in iOS Settings → PythonDeck. Data read through these permissions stays on your device unless your own code sends it somewhere. Access to health data (HealthKit) is not enabled in the current released version of this app.

1.5 Services You Connect to Yourself

Online features send data only to the endpoints you configure, and only while you actively use that feature — for example the prompt and code you submit to an AI provider, the PyPI requests when you install a package, your git push to a remote repository, or the SSH/SFTP traffic of remote development against a server you own. Those endpoints and credentials come from you: the AI features run on your own API key and provider account. Quota, invoicing and usage are settled directly between you and the provider — we take no part in that billing and have no access to your provider account.

Using these features therefore means complying with the provider's own terms of service and usage policies, including any rules on automated calls, content use and redistribution, at your own cost. The privacy policies of those services apply to that traffic, and we do not receive or store a copy of it on our own servers. You are also responsible for the servers you connect to and for the commands you run on them.

2. Information We Do Not Collect

  • No name, email address, phone number or user account
  • No advertising identifiers, no contact or address book data
  • No analytics or tracking SDK is embedded in the app
  • No payment or billing details — memberships are billed by Apple and verified on your device (see 1.1)
  • No location, photos, camera or microphone data sent to us
  • We do not sell or share your data

3. Purpose of Data Usage

  • To provide core functionality: editing, running, debugging and version-controlling your code on device
  • To verify PythonDeck Pro membership status so purchased benefits apply on your device
  • To keep your secrets safe so that AI, Git and SSH features can authenticate on your behalf
  • To serve the home-screen widget and Shortcuts (“Run Python Script”) with the local data they display
  • To respond to support requests you send us by email

4. Third-Party Services Used

The services below are contacted directly from your device, at your instruction, for the corresponding feature. They are not used for advertising or cross-app tracking.

5. Data Retention and Deletion

  • You can delete projects, files, run history and snapshots at any time inside the app, or export them to the iOS Files app.
  • You can revoke device permissions at any time in iOS Settings.
  • Membership status is not kept by us: it is re-read from StoreKit each time the app checks entitlements, so there is no purchase record of yours on our side to delete. Cancelling or refunding a purchase is handled by Apple and takes effect on the device at the next check.
  • Deleting the app removes the sandboxed project data it contains.
  • Keychain items may survive an app reinstall due to iOS behavior. To remove them completely, delete your stored secrets in Settings → Secrets (Keychain), and clear AI keys, Git credentials and SSH hosts before uninstalling.

Since we operate no servers, there is no copy of your data on our side to retain or hand over. If you contact us by email, the message you send is kept only as long as needed to answer you, and you can ask us to delete it.

6. Data Security

  • All user content stays inside the app sandbox on your device; we maintain no servers that store it
  • Membership verification is performed locally by StoreKit; we keep no receipts, transaction logs or purchase history
  • Secrets are stored in the iOS Keychain and are never synced or written into project files, exports or logs
  • Network requests for packages, Git over HTTPS and AI calls use HTTPS with certificate validation (bundled CA store). The app's encryption usage falls entirely within the exemptions available under the U.S. Export Administration Regulations, so the Info.plist key ITSAppUsesNonExemptEncryption is set to false. See section 7 (Export Compliance) below for details.
  • SSH host keys use trust-on-first-use with stored SHA256 fingerprints; a changed fingerprint blocks the connection unless you re-confirm it
  • The AI assistant requires per-capability approval (Read / Write / Execute / Network / Install / Git), and file changes must be accepted through a diff view
  • If you enable “Share iPhone Analytics with Developers” at the system level, Apple may provide us with anonymous crash and performance diagnostics; we do not add our own analytics on top of these

7. Export Compliance

PythonDeck bundles standard open-source cryptography libraries so that user scripts can implement their own security workflows. In particular:

  • Transport: HTTPS and WSS requests to PyPI, Git remotes, AI providers and MCP servers use iOS's URLSession / Security.framework stack (Apple-supplied TLS). Git-over-SSH uses swift-crypto, which is a wrapper over Apple's CryptoKit.
  • Bundled third-party cryptography: The cryptography Python package (currently 47.0.0, built against OpenSSL 3.x via Rust/cffi) is pre-installed inside the app bundle so user scripts can import it offline. Symmetric algorithms ship at up to AES-256; asymmetric algorithms ship at RSA-4096 and Ed25519.
  • At-rest: Only the iOS Keychain (Apple's hardware-backed storage) is used for API keys and credentials. No proprietary ciphers are implemented by us.

This distribution falls within the "mass market" commodity category under U.S. Export Administration Regulations (EAR) §740.17(b)(1), which permits worldwide public distribution of standard encryption software through consumer channels such as the Apple App Store. No individual export license from the U.S. Bureau of Industry and Security (BIS) is required for PythonDeck's distribution scope.

Notice to users (EAR §740.17(e)(2)): Export and re-export of encryption software and technology is regulated by the United States and other countries. PythonDeck and its bundled cryptography components may not be lawfully exported or re-exported to any country or person listed on the U.S. Treasury's Specially Designated Nationals list or subject to a U.S. comprehensive embargo. By downloading or using this app, you agree to comply with all applicable export-control laws and to not use the app for any purpose prohibited by those laws.
