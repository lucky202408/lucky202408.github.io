🛠 问题反馈指南 / Issue Reporting Guide

为了更高效地定位问题，请在邮件中包含：

Please include the following details:

  • 设备与系统版本 / Device & OS version（iPhone · iOS 18 / Mac · macOS 15）
  • Helmic 版本 / Helmic app version
  • 所在页面或功能 / Which page or feature（销售、评论、版本、构建、TestFlight 等）
  • 是否为 Apple 接口返回的错误，并附上应用内显示的错误文字 / Any error text shown in the app
  • 问题描述与复现步骤 / Description & steps
  • 相关截图（如有）/ Screenshots if available
🔐 安全提示 / Security note
请不要在邮件中附上你的 API 私钥（.p8 文件内容）、完整的 Key ID 或 Issuer ID——我们不需要它们就能排查，而拿到它们的人可以改动你商店里的数据。若已误发，请立即在 App Store Connect 中吊销该密钥并重新生成。
Please never attach your private key, full Key ID or Issuer ID to a support email. If you already sent one, revoke that key in App Store Connect right away.

🔑 凭证与账号 / Credentials & Accounts

Helmic 不运营任何服务器，你的 App Store Connect API 凭证只保存在你自己设备的钥匙串里。因此我们无法代你查询、恢复或重置密钥。

Helmic runs no servers, and your API credential lives only in your device's Keychain, so we cannot look it up, restore or reset it for you.

  • 密钥失效、权限不足或需要重建：请在 App Store Connect →「用户和访问」→「集成」→「App Store Connect API」中自行操作
  • Regenerate a key under App Store Connect → Users and Access → Integrations → App Store Connect API
  • 换了新设备：在新设备上重新添加同一组凭证即可，旧设备上的可在应用内删除
  • Replace a device by adding the same credential again; remove it from the old device in Helmic's settings
